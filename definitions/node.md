**Node** — это физический или виртуальный сервер в Kubernetes-кластере, который предоставляет ресурсы (CPU, память, дисковое пространство, сеть) для запуска Pod’ов.

**Ключевые моменты:**
- На Node работает **kubelet**, который управляет Pod’ами и контейнерами.
- Node может быть **Control Plane (Master)** или **Worker (рабочий)**.
- Каждый Pod размещается на конкретной Node через **kube-scheduler**.
- Node обеспечивает **изоляцию ресурсов**, сетевые интерфейсы и доступ к хранилищу.

```bash
kubectl get nodes              # список всех Node

kubectl top node               # использование ресурсов Node
